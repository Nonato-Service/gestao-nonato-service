Manual do Programa — capturas de ecrã (opcional)
================================================

O manual in-app usa representações visuais CSS por módulo.
Para adicionar screenshots reais no futuro:

  public/manual/assets/{locale}/{pageId}/01.webp

Exemplo:
  public/manual/assets/pt-BR/clientes-default/01-lista.webp

Idiomas: pt-BR, es, fr, it, de, en
